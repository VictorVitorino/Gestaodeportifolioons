# TMG · Diagnóstico e Reorganização (versão executiva interativa)

Apresentação em HTML de arquivo único, com 15 telas e navegação por tela (botão **Avançar**, setas do teclado, gesto de arrastar ou pontos no rodapé). Tecla **F** abre em tela cheia. Abra `index.html` direto no navegador.

**Fluxo:** Gestão de Mudanças/ADKAR → Método → Diagnóstico (dashboard) → Evidências → Leitura ADKAR → Simulador de matriz → Sistema de causas → Benchmarks → Princípios → Reorganização cultural → Matriz equilibrada → Fluxo, squads e capacidade → Modelo futuro → Recomendações.

**Interações:** cartas ADKAR que viram; dashboard clicável; jogo "adivinhe quantas entrevistas"; simulador de estrutura (funcional → projetizada); mapa de causas navegável; abas de benchmarks; alternância HOJE/FUTURO; matriz de interseções; simulador demanda × capacidade; montagem de squad; checklist de decisões com medidor de prontidão.

**Regras de conteúdo**
- A leitura é consolidada. Não há nomes nem identificação de entrevistas (E1, E2…), e as contagens aparecem como "x de 7 entrevistas".
- Cada tela segue a sequência FATO → DADO → INSIGHT → IMPLICAÇÃO. Quando uma dimensão tem pouca evidência (1–2 fontes), isso vem sinalizado.
- A leitura de "matriz fraca" é interpretativa e acompanha uma ressalva explícita.
- O modelo matricial equilibrado (comunidades de entrega × capacidades compartilhadas, fóruns e gestão de capacidade) é usado apenas como referência metodológica A&M. As comunidades e a intensidade de alocação são **ilustrativas**, a definir em workshop.
- Benchmarks (Bayer, Cargill, Ford, Unilever): dados públicos, com as fontes no rodapé.
