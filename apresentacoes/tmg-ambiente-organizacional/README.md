# TMG · Ambiente Organizacional — apresentação executiva

Apresentação em HTML único (`index.html`), página por página, construída exclusivamente a partir das entrevistas e diagnósticos registrados entre 27/08 e 29/09/2026.

## Como usar

- Abra `index.html` no navegador (funciona offline; as fontes Barlow Condensed e Inter vêm do Google Fonts e têm fallback local).
- Navegação: botões **Avançar/Voltar**, setas ← →, espaço, `Home`/`End`, **I** abre o índice, **F** alterna tela cheia. Em telas touch, deslize para os lados.
- Cada página tem endereço próprio (`index.html#25`).
- Passe o mouse sobre gráficos e diagramas para ver o valor e a origem de cada ponto.
- Impressão/PDF: `Ctrl+P` gera uma página por slide (1600×900).

## Estrutura (53 páginas)

| Capítulo | Páginas |
|---|---|
| Capa, agenda e protocolo de leitura | 1–3 |
| 01 · Dimensões avaliadas e método | 4–10 |
| 02 · Contexto e resumo executivo | 11–16 |
| 03 · Modelo de operação matricial | 17–22 |
| 04 · Mapa de resultados das entrevistas | 23–29 |
| 05 · Benchmark de mercado (10 casos) | 30–37 |
| 06 · Reorganização proposta | 38–50 |
| Apêndices (fontes, referências, dados) | 51–53 |

## Regras de conteúdo aplicadas

- Nenhum nome de entrevistado aparece; as fontes são codificadas de E1 a E7, em ordem cronológica.
- Cada bloco é marcado como **Fato**, **Percepção**, **Interpretação**, **Referência externa** ou **Proposta**.
- Dados não registrados (horas de entrevista, dados financeiros) são declarados como não registrados.
- Índices harmonizados (0–100) usam `(nota − mínimo) ÷ (máximo − mínimo) × 100` sobre as escalas dos próprios instrumentos.
- Casos de benchmark citam fontes públicas verificáveis (Apêndice B).
